# KartIQ V6.0.22 — Focus Sprint

La carte du pilote suivi dans `#sprintFocus` adopte la même hiérarchie que le Focus Endurance :

- `#sprintFocusPosition` ;
- `#sprintFocusName` ;
- `#sprintFocusLastRank`, rendu avec l’icône chronomètre SVG blanche et le rang numérique sans suffixe.

Les styles sont isolés sous `#sprintFocus` afin de ne pas modifier le Focus Endurance, le Focus Qualification ou les autres écrans Sprint.
