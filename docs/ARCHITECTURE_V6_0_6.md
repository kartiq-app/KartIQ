# KartIQ V6.0.6 — Trois filets Endurance orange

La page Endurance reste un clone strict de Qualification.

Seuls les trois accents suivants sont surchargés lorsque `data-app-mode="endurance"` :

- `.qual-strip` : filet horizontal supérieur en `#FF8A00` ;
- `.qual-table-wrap` : filet horizontal au-dessus du classement en `#FF8A00` ;
- `.position-cell` : filet vertical gauche en `#FF8A00`.

Les séparateurs gris, le Focus et les autres modes ne sont pas modifiés.
