# KartIQ V6.0.5 — Endurance clone strict de Qualification

## Principe

Le mode métier reste `endurance`, mais l’écran affiché est directement `#qualification`.

Aucun style propre à Endurance n’est appliqué :

- mêmes informations ;
- mêmes couleurs ;
- mêmes filets ;
- mêmes mises en page desktop, portrait et paysage ;
- même Focus ;
- mêmes comportements et synchronisation Apex.

Les futures personnalisations Endurance devront être ajoutées uniquement sur demande explicite.
