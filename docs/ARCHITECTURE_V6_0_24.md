# KartIQ V6.0.24 — Deltas Sprint et Focus

## Règles métier

### Sprint
- P1 : écart avec P2, couleur verte.
- P2 et suivants : intervalle Apex du pilote suivi avec le pilote immédiatement devant, couleur orange.

### Focus Sprint et Focus Endurance
- Bloc supérieur orange : écart avec le pilote immédiatement devant.
- Bloc inférieur vert : intervalle Apex du pilote immédiatement derrière avec le pilote suivi.
- Le champ `gap` (écart au leader) n’est jamais utilisé pour calculer le delta inférieur.
