# KartIQ V5.5.5 — Classements Sprint responsive

## Smartphone paysage

- Les valeurs Temps restant et Tours gagnent encore 30 % par rapport à la V5.5.4.
- La règle est limitée aux écrans tactiles en orientation paysage de 950 px ou moins.
- La colonne Intervalle est masquée dans le classement Sprint afin de libérer de la largeur pour le pilote et le dernier tour.

## Smartphone portrait

Le classement Sprint affiche désormais exactement les mêmes informations que le classement Qualification portrait :

- position ;
- kart, uniquement si Apex fournit le numéro ;
- pilote ;
- dernier tour ;
- meilleur tour ;
- écart.

La colonne Intervalle est masquée dans cette vue. Desktop, Focus et Endurance ne sont pas modifiés.
