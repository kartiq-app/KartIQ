# KartIQ V6.0.10 — Filets Endurance

La page Endurance conserve la structure de Qualification, avec uniquement les accents suivants :

- filet horizontal supérieur : `#FF8A00` ;
- filet horizontal au-dessus du classement : `#FF8A00` ;
- filet vertical de la case Menu : gris `#29292E` ;
- filet vertical de la case Position : `#FF8A00` ;
- séparateurs de lignes : gris, inchangés.

Les autres modes ne sont pas modifiés.
