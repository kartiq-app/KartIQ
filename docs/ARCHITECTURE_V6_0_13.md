# KartIQ V6.0.13 — Focus Endurance métier

Le Focus Endurance possède désormais sa propre présentation, sans modifier le Focus Sprint.

- bloc pilote : position, nom et rang du dernier tour ;
- bloc delta : noms et écarts des concurrents immédiatement devant et derrière ;
- bloc session : temps restant et tours ;
- bloc dernier tour : dernier chrono de l’entité suivie en grand.
