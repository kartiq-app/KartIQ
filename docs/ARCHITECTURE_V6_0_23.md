# KartIQ V6.0.23 — Focus Sprint

La carte du pilote suivi du Focus Sprint reprend le bloc visuel du Focus Endurance :

1. Position
2. Nom du pilote ou de l’équipe
3. Icône chronomètre blanche + rang numérique, sans espace ni suffixe

Le rang et l’icône utilisent la police et le traitement F1 Regular.
