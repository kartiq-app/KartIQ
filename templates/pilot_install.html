Ajoute Velocity à ton écran d'accueil pour ouvrir le Focus Endurance directement, sans email ni compte.

Sur iPhone — Safari
  1. Ouvre ce lien dans Safari (pas dans le navigateur de WhatsApp).
  2. Touche Partager ▢↑, puis Sur l'écran d'accueil.
  3. Touche Ajouter, puis ouvre l'icône Velocity Pilote.
Sur Android — Chrome
  1. Ouvre ce lien dans Chrome.
  2. Touche Installer l'application ci-dessous, ou utilise le menu ⋮ → Installer l'application / Ajouter à l'écran d'accueil.
  3. Ouvre l'icône Velocity Pilote depuis l'accueil.
Installer sur téléphone

Sur iPhone, ouvre le lien dans Safari et utilise Partager → Sur l'écran d'accueil. Sur Android, ouvre-le dans Chrome et utilise Installer l'application.
